# EN Silver Pines Community Translate (PL)

**Multilingual subtitle mod for Silver Pines Demo** — a community translation framework based on BepInEx.

##  Features

- **Full Polish translation** (3184+ strings, 99.6% coverage)
- **Expandable framework** — add any language: Czech, German, Russian…
- **Instant deployment** — no game recompilation required
- **Voice subtitles** — radio, TV, dialogue — everything translated
- **Proper font rendering** — Polish characters (ą ę ł ó) display correctly

##  Installation

### Requirements
- **Silver Pines Demo** (Steam)
- **BepInEx 5.4.23** ([Download](https://github.com/BepInEx/BepInEx/releases))

### Steps
1. **Install BepInEx**: Extract it into the game folder (`Silver Pines Demo/`)
2. **Launch the game once** so BepInEx can create the folder structure
3. **[Download the mod](https://github.com/marczukmichal/SilverPinesCommunityTranslatePL/releases/Beta/)** (0.4 MB)
4. **Extract to**: `Silver Pines Demo/BepInEx/plugins/SilverPinesTranslate/`
5. **Restart the game** — Polish is now active

 **Done!** Start a new game or continue your save. Some preloaded text may remain in English until you re-enter the location.

# 🇵🇱 Silver Pines Community Translate (PL)

**Wielojęzyczny mod napisów do Silver Pines Demo** — społeczniowy framework tłumaczeń na bazie BepInEx.

##  Cechy

- **Pełne tłumaczenie polskie** (3184+ stringi, 99.6% pokrycia)
- **Rozszerzalny framework** — dodaj dowolny język (czeski, niemiecki, rosyjski…)
- **Natychmiastowe wdrażanie** — bez rekompilacji gry
- **Napisy głosowe** — radio, TV, dialogi — wszystko przetłumaczone
- **Prawidłowe renderowanie fontów** — polskie znaki (ą ę ł ó) wyświetlane poprawnie

##  Instalacja

### Wymagania
- **Silver Pines Demo** (Steam)
- **BepInEx 5.4.23** ([Pobierz](https://github.com/BepInEx/BepInEx/releases))

### Kroki
1. **Zainstaluj BepInEx**: Rozpakuj do folderu gry (`Silver Pines Demo/`)
2. **Uruchom grę raz**, aby BepInEx stworzył strukturę folderów
3. **[Pobierz mod](https://github.com/marczukmichal/SilverPinesCommunityTranslatePL/releases/Beta/)** (0.4 MB)
4. **Rozpakuj do**: `Silver Pines Demo/BepInEx/plugins/SilverPinesTranslate/`
5. **Zrestartuj grę** — Polski jest teraz aktywny

 **Gotowe!** Zacznij nową grę albo kontynuuj zapis (niektóre pre-załadowane teksty zostają po angielsku aż do ponownego wejścia do lokacji).
